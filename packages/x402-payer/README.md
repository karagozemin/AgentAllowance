# @agentallowance/x402-payer

Stellar x402 payment construction, facilitator verification/settlement client, and exact receipt
binding used by [`@agentallowance/sdk`](https://www.npmjs.com/package/@agentallowance/sdk).

This is a low-level package. Most applications should install `@agentallowance/sdk` instead.

Testnet-first, unaudited software. MIT licensed.
