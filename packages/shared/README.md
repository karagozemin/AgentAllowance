# @agentallowance/shared

Typed x402 v2 payloads, policy decisions, atomic amount helpers, reason codes, receipt codecs, and
stable hashing used by [`@agentallowance/sdk`](https://www.npmjs.com/package/@agentallowance/sdk).

This is a low-level package. Most applications should install `@agentallowance/sdk` instead.

Testnet-first, unaudited software. MIT licensed.
