# @agentallowance/stellar-smart-account-auth

Builders and strict validators for the two-entry delegated Soroban authorization used by
[`@agentallowance/sdk`](https://www.npmjs.com/package/@agentallowance/sdk).

This is a low-level package. Most applications should install `@agentallowance/sdk` instead.

Testnet-first, unaudited software. MIT licensed.
